# Auction Helper

Standalone Chrome side-panel extension for organizing YoWorld auction lots.

Current build: **v1.4.1**

Features include YoWorld.info item search, single and bundle lots, reserve/starting-bid tracking, sold/no-sale status, buyer/final price tracking, JSON backup/restore, and CSV export.

The project is independent from YoInventory Suite. Future updates should preserve the existing extension identity and stored auction data.
